AI Fraud Detection Frontend
============================

A professional banking-style static frontend for an academic AI-based fraud detection project.

Files:
- index.html  -> main website
- style.css   -> responsive banking-style UI
- script.js   -> charts, filters and simulated transaction scoring

Run:
1. Extract the folder.
2. Open index.html in Chrome/Edge.
3. For deployment, upload the three files to any static hosting service.

Notes:
- Uses Chart.js from a CDN for the dashboard charts.
- No real banking/customer data is included.
- The displayed scores and metrics are demonstration values only.
